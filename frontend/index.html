C++ Data Structures Specification & Academic Defense Sheet

VIT Pune Semester 3 IT Department · Group 8 | 100% Scratch Custom C++ Implementation (Zero STL Containers)

1 Hash Table (Asset Registry) Search: O(1) avg | Insert: O(1) avg | Space: O(N)

Built with Separate Chaining collision handling using custom singly-linked HashNode buckets and polynomial rolling hash (djb2 variant). Automatically doubles bucket capacity and rehashes when load factor exceeds 0.75. Avoids linear probing clustering cascades.

2 Doubly Linked List (Maintenance & Fault History) Append: O(1) | Prepend: O(1) | Space: O(H)

Maintains an interleaved chronological audit log of fault reports and recalibrations per asset. Direct head and tail pointer updates support O(1) tail appends and bidirectional traversal for computing linear measurement drift velocity: Drift = Delta(Dev) / Delta(Time).

3 Binary Max-Heap (Emergency Fault Triage Queue) peekMax: O(1) | Insert: O(log N) | extractMax: O(log N)

Array-backed complete binary tree ordering tasks by live Composite Risk Score: Risk = 3*Severity + 2*DaysOverdue + 5*|DriftVelocity| multiplied by the Graph Blast Multiplier. Sift-up percolation on insertion and sift-down on dispatch guarantee strict log-time priority queue invariants without STL.

4 AVL Tree (Calibration Compliance Range Index) Search: O(log N) | Insert: O(log N) | Range Query: O(log N + K)

Self-balancing binary search tree indexed by next_calibration_due epoch timestamp. Maintains balance factor |BF| <= 1 via Left-Left (LL), Right-Right (RR), Left-Right (LR), and Right-Left (RL) rotations, guaranteeing O(log N + K) range queries.

5 Circular Queue (Service Desk Intake Buffer) Enqueue: O(1) | Dequeue: O(1) | Memory: Fixed Bounded

Fixed-capacity, memory-bounded array buffer with modulo wrap-around arithmetic: (index + 1) % capacity. Acts as the intake gate, protecting downstream data structures from memory saturation during high-volume fault storms.

6 Undo Stack (LIFO Transaction Rollback) Push: O(1) | Pop: O(1) | Space: O(U)

Dynamically sized LIFO stack storing inverse transaction delta snapshots. Reverses accidental dispatches and report entries atomically in O(1) time.

7 Merge Sort (Compliance & Quality Sorter) Time: O(N log N) Guaranteed | Space: O(N) Stable

Divide-and-conquer stable sorting algorithm that ranks assets by accumulated downtime, fault frequency, or calibration urgency without std::sort.

8 Directed Graph (Adjacency List) & BFS/DFS (Blast Radius) BFS/DFS: O(V + E) | Space: O(V + E)

Custom adjacency list modeling laboratory equipment dependencies. Breadth-First Search (BFS) computes systemic blast radius when an upstream power or network asset fails, and identifies Single Points of Failure (SPOFs).
